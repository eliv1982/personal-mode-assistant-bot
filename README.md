# ModeMate AI

**ModeMate AI** — Telegram LLM-assistant with role modes, memory and usage statistics.

Личный AI-помощник в Telegram для ежедневных задач: планирование дня, принятие решений, редактирование текстов, обучение и генерация идей.

> Репозиторий: `personal-mode-assistant-bot`

---

## Что делает ModeMate AI

Бот общается через OpenAI и поддерживает **5 специализированных режимов**. Каждый режим — отдельный системный промпт из `prompts.json`, настраивающий поведение AI под конкретную задачу. Бот запоминает контекст диалога (краткосрочная память), ведёт журнал расходов токенов и позволяет в один клик посмотреть детали любого запроса.

## Режимы

| Режим | Ключ | Описание |
|---|---|---|
| 📅 Планировщик дня | `daily_planner` | Мягко раскладывает задачи по приоритетам, строит реалистичный план без токсичной продуктивности |
| ⚖️ Помощник по решениям | `decision_helper` | Сравнивает варианты, показывает плюсы/минусы, риски и нейтральный вывод |
| ✍️ Редактор текста | `text_polisher` | Улучшает письма, посты и формулировки: яснее, мягче, увереннее, короче |
| 🎓 Учебный помощник | `learning_coach` | Объясняет темы, код и домашние задания простым языком, по шагам и с примерами |
| 💡 Лаборатория идей | `idea_lab` | Генерирует идеи для проектов, названий, UX, фич и улучшений |

Режимы хранятся в `prompts.json` и легко редактируются без изменения кода.

## Память

- Каждый чат (`chat_id`) хранит независимую историю в `data/memory.json`.
- Для каждого `chat_id` сохраняются: выбранный режим и последние N сообщений (пар user/assistant).
- Число сообщений ограничено `MEMORY_LIMIT` (по умолчанию 20).
- В OpenAI передаётся: `system_prompt` выбранного режима + последние N сообщений + новое сообщение.
- `/reset` очищает историю, но **не сбрасывает** режим и **не трогает** статистику расходов.
- Если файл памяти отсутствует — создаётся автоматически. Если повреждён — ошибка логируется, бот продолжает работу с пустой памятью.

## Форматирование ответов

Все системные промпты содержат правила Telegram-friendly форматирования:
- Без Markdown-заголовков (`#`, `##`, `###`)
- Без Markdown-таблиц
- Блоки кода только если пользователь явно просит написать/показать код
- Для списков: символ `•` или цифровая нумерация (`1. 2. 3.`)
- Ответы отправляются без `parse_mode`, чтобы избежать артефактов разметки

Служебные сообщения бота (команды, статистика) формируются кодом и используют безопасный HTML.

## Usage Log и статистика

После каждого LLM-ответа под сообщением появляется кнопка **📊 Детали запроса**.

Нажатие показывает:
- Режим и модель
- Дата и время запроса
- Входящие / исходящие / всего токенов
- Стоимость в USD и ₽
- Курс ЦБ РФ и дата курса
- Предупреждение `⚠️ fallback`, если ЦБ был недоступен

Все записи сохраняются в `data/usage.json` (без текста запросов и ответов — только метрики).

### /stats — агрегированная статистика

Команда `/stats` показывает по текущему `chat_id`:

| Метрика | За всё время | Сегодня | За месяц |
|---|---|---|---|
| Запросов | ✓ | ✓ | ✓ |
| Токенов | ✓ | ✓ | ✓ |
| Стоимость USD | ✓ | ✓ | ✓ |
| Стоимость ₽ | ✓ | ✓ | ✓ |

Рублёвые значения в `/stats` пересчитываются по актуальному курсу ЦБ РФ на момент запроса статистики.

**Важно:**
- Стоимость **примерная** — считается по ценам из `.env` (`OPENAI_INPUT_PRICE_PER_1M`, `OPENAI_OUTPUT_PRICE_PER_1M`).
- Рубли считаются по курсу ЦБ РФ на дату формирования статистики, а не по историческим курсам.
- `/reset` не сбрасывает статистику. Для сброса используйте `/resetstats` (с подтверждением inline-кнопками).

## Cost Tracking

```
input_cost  = input_tokens  / 1_000_000 × OPENAI_INPUT_PRICE_PER_1M
output_cost = output_tokens / 1_000_000 × OPENAI_OUTPUT_PRICE_PER_1M
total_usd   = input_cost + output_cost
total_rub   = total_usd × usd_rub_rate
```

**Курс USD/RUB** берётся из официального XML-фида ЦБ РФ:
`https://www.cbr.ru/scripts/XML_daily.asp`

Если ЦБ недоступен, используется `USD_RUB_FALLBACK` из `.env` (по умолчанию `100.0`), а в деталях запроса появляется пометка `⚠️ fallback`.

## Создание `.env`

```bash
cp .env.example .env
```

```dotenv
# Telegram
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# OpenAI
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o-mini

# Цена токенов (USD за 1M). Актуальные цены: https://openai.com/pricing
OPENAI_INPUT_PRICE_PER_1M=0.15
OPENAI_OUTPUT_PRICE_PER_1M=0.60

# Память диалога
MEMORY_LIMIT=20

# Fallback-курс если ЦБ РФ недоступен
USD_RUB_FALLBACK=100.0
```

> **Никогда не коммитьте `.env`.** Он уже включён в `.gitignore`.


## Идеи для развития

- **Auto-router** — определять подходящий режим по задаче пользователя автоматически, без ручного `/mode`
- **Предложение сменить режим** — если задача лучше подходит другой роли, мягко предлагать переключиться
- **Small talk на старте** — краткое приветственное взаимодействие для новых пользователей
- **Feedback от пользователя** — сбор оценок ответов и отчёт о незакрытых сценариях для администратора
- **Расширенная персонализация** — настройки обращения, языка, длины ответа и preferred tone
